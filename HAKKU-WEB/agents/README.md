# HAKKU --- Paket Spesifikasi (Traspac Competition 2027)

Paket ini berisi spesifikasi induk dan tujuh dokumen turunan. Mulai dari
`00-spesifikasi-induk.md`; dokumen lain harus konsisten dengannya.

## Daftar file

-   `00-spesifikasi-induk.md` --- visi, keputusan Fixed/Proposed/To
    Validate/Deferred.
-   `01-prd.md` --- kebutuhan produk dan acceptance criteria.
-   `02-technical-requirements.md` --- persyaratan teknis.
-   `03-app-flow.md` --- alur aplikasi dan journey.
-   `04-design-brief.md` --- arahan desain dan aksesibilitas.
-   `05-backend-scheme.md` --- model data, API, otorisasi.
-   `06-implementation-plan.md` --- fase implementasi dan gerbang rilis.
-   `07-agents.md` --- instruksi untuk AI coding agent.

Dokumen ini adalah baseline rancangan, bukan bukti bahwa aplikasi atau
integrasi sudah dibangun. Sumber hukum, kepatuhan, keamanan, dan kerja
sama mitra perlu divalidasi sebelum penggunaan perkara nyata.


## Acuan kompetisi

Paket ini diselaraskan dengan Guide Book Traspac Competition 2027:
- Bidang target: Web/Mobile Apps.
- Tema yang paling relevan: Sosial.
- Tenggat pengumpulan karya: 30 Desember 2026.
- Artefak pengumpulan: video, pitch deck, software sistem; source code GitHub ditautkan di pitch deck.
- Prioritas implementasi mengikuti aspek penilaian lomba: logika, UI, keamanan, kemudahan instalasi, kreativitas, performa, pemahaman kode, database, dan kerapian.

Guide book tidak menentukan durasi/format teknis video atau pitch deck secara rinci; periksa pengumuman terbaru panitia. Semua teknologi tetap Proposed sampai dipilih dan diuji di repository nyata.
